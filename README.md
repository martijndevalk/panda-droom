# 🐼 Panda Droom — Getallenreis & Tijdreis

Een vriendelijke, stressvrije en didactisch verantwoorde educatieve webapplicatie waarmee kinderen spelenderwijs **de tafels van vermenigvuldiging** én **leren klokkijken** (analoog en digitaal). 

Geleid door de vrolijke, interactieve Panda reizen kinderen door kleurrijke werelden vol ontdekkingen, visuele ondersteuning en positieve bekrachtiging.

**[▶ Bekijk de Live Demo](https://martijndevalk.github.io/panda-droom/)**

---

## 🎯 Doelgroep & Didactische Filosofie

### 👥 Voor wie is Panda Droom ontworpen?

1. **Jonge Leerlingen (Basisonderwijs Groep 3 t/m 6 — Leeftijd 6 t/m 10 jaar)**:
   - **Groep 3 & 4**: Kennismaking met hele en halve uren op de klok, herhaald optellen en de eerste tafels (1, 2, 5, 10).
   - **Groep 5 & 6**: Kwartieren, minuten, 24-uurs digitale klok en alle tafels t/m 10 inclusief gemengde herhaling.
2. **Kinderen met Specifieke Leerbehoeften**:
   - **Rekenmoeite & Dyscalculie**: Geen tikkende tijdsbalken of negatieve scores. Foutjes worden vriendelijk opgevangen met opbouwende visuele hints.
   - **Concentratie-uitdagingen & ADHD**: Afleidingsvrije, overzichtelijke schermen, korte behapbare leersessies en een dagelijkse voltooiingslimiet (2 levels per dag) om overprikkeling tegen te gaan.
   - **Dyslexie & Leesproblemen**: Alle sommen, instructies en kloktijden worden natuurlijk voorgelezen via spraaksynthese (ElevenLabs TTS of Web Speech API).
   - **Faalangst**: Falen bestaat niet in Panda Droom; een foutje is slechts een uitnodiging om samen met Panda opnieuw te kijken.
3. **Ouders & Docenten**:
   - Een veilige, advertentievrije en privacy-vriendelijke leeromgeving.
   - Ouderportaal met voortgangsoverzicht en aanpasbare beloningen (bijv. samen koekjes bakken na 20 sterren).

## 🌟 Twee Complete Leertrajecten

Panda Droom biedt twee naadloos geïntegreerde reizen die kinderen via één intuïtieve schakelaar in de header kunnen verkennen:

┌─────────────────────────┐                     ┌─────────────────────────┐
│   🔢 GETALLENREIS       │                     │     ⏰ TIJDREIS         │
│   (Tafels 1 t/m 10)     │                     │     (Klokkijken)        │
├─────────────────────────┤                     ├─────────────────────────┤

### 1. 🔢 Panda's Getallenreis (Tafels Oefenen)
- **Didactische Tafelvolgorde**: Opgebouwd van makkelijk en herkenbaar naar complexer (1 → 10 → 2 → 5 → 3 → 4 → 6 → 7 → 8 → 9).
- **C-P-A Didactiek**:
  - *Concreet*: Bamboestengels en voorwerpen tellen.
  - *Pictoraal*: Sprongen op de getallenlijn en tegelroosters.
  - *Abstract*: Formele sommen met interactief kindvriendelijk numpad.
- **Tafels Oefenplein (Vrij Spelen)**: Vrij kiezen welke tafel je wilt oefenen met directe feedback.

### 2. ⏰ Panda's Tijdreis (Klokkenreis)
- **Klokkijken Volgens Basisonderwijs Methodiek**:
  - Wereld 1: Hele uren (1:00, 2:00, etc.)
  - Wereld 2: Halve uren (half 3 = 2:30)
  - Wereld 3: Kwartieren (kwart over & kwart voor)
  - Wereld 4: 5 en 10 minuten (over en voor)
  - Wereld 5: Analoog naar Digitaal & 24-uurs notatie
- **Interactieve Analoge Klok**: Volledig met de vinger of muis draaibare grote en kleine wijzer, dynamische kleuring van de "OVER" en "VOOR" zones, en taartpunt-sectoren.
- **Klokkenplein**: Vrij aan de klok draaien met een dynamisch meekleurende dag/nacht hemel en Panda die de tijd live uitspreekt.

## ✨ Belangrijkste Features

- 🐼 **Interactieve Panda Avatar**: Reageert dynamisch op acties met levendige SVG-animaties (nadenken, juichen, knipperen, slapen).
- 🏆 **Schatkist & Beloningssysteem**: Sterren en munten verdienen, trofeeën ontgrendelen en beloningen claimen.
- 👨‍👩‍👧 **Ouderportaal**: Ouders kunnen gepersonaliseerde beloningen instellen (bijv. "Filmavond kiezen", "Pannenkoeken bakken").
- 🔊 **Audio & Text-to-Speech**: Warme geluidseffecten, ontspannende achtergrondmuziek en spraak via ElevenLabs of Web Speech.
- 📳 **Haptische Feedback**: Voelbare trillingen op mobiele apparaten bij het draaien aan de klokwijzers of beantwoorden van vragen.
- 📱 **Progressive Web App (PWA)**: Direct te installeren op iPad, tablet en smartphone; werkt offline via de ingebouwde Service Worker.
- 🎨 **Consistente Toy-Box Stijl**: Grote tastbare knoppen met diepe cartoon-randen (`shadow-[3px_3px_0px_#2D3436]`) en oogvriendelijke kleuren.

## 🛠️ Tech Stack & Architectuur

| Categorie | Technologie | Toelichting |
|---|---|---|
| **Framework** | [Astro](https://astro.build/) 5 | Snelle Static Site Generation & View Transitions |
| **UI Library** | [React](https://react.dev/) 18 | Interactieve islands en reactieve state management |
| **Styling** | [Tailwind CSS](https://tailwindcss.com/) v4 | Utility-first styling en custom design tokens |
| **UI Kit** | [DaisyUI](https://daisyui.com/) 5 | Thema- en componentondersteuning |
| **Animaties** | [Motion](https://motion.dev/) | Vloeiende micro-interacties en schermovergangen |
| **Audio** | [Howler.js](https://howlerjs.com/) | Beheer van effecten (SFX) en achtergrondmuziek (BGM) |
| **Haptics** | [Web Haptics](https://github.com/vlad-stoenescu/web-haptics) | Voelbare vibraties via de browser Web Haptics API |
| **Spraak (TTS)** | [ElevenLabs API](https://elevenlabs.io/) | Natuurlijke Nederlandse stemmen met Web Speech fallback |
| **Iconen** | [Lucide React](https://lucide.dev/) | Heldere vector iconen |
| **Effecten** | [canvas-confetti](https://github.com/catdad/canvas-confetti) | Vrolijke beloningsconfetti bij mijlpalen |
| **Type Safety** | TypeScript | Volledig type-veilig |

## 🚀 Aan de Slag

### Vereisten
- [Node.js](https://nodejs.org/) v20 of hoger
- npm

### Installatie
```bash
npm install
```

### Ontwikkelserver Starten
```bash
npm run dev
```
Open [http://localhost:4321/panda-droom/](http://localhost:4321/panda-droom/) in je browser.

### Productie Build & Testen
```bash
# Productiebundel genereren
npm run build

# Preview van de statische dist draaien
npm run preview
```
